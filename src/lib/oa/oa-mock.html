Mock Outdoor Analytics

This page is a stand-in for hub.outdooranalytics.com. It stores a fake JWT in sessionStorage["gb_session_token"]. It does not call Outdoor Analytics.

  1. Run Desk with npm run dev and set DESK_PUBLIC_ORIGIN to this origin (for example http://127.0.0.1:3000).
  2. Sign in to Desk if DESK_AUTH_SECRET is set. The popup needs that session.
  3. Set a fake token below, then drag Connect OA from Import to the bookmarks bar — or use the link loaded from Desk below.
  4. Click the bookmark on this page. A Desk window opens and saves the token. The fake token must not appear in the address bar.
